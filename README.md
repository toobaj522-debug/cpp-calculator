# C++ Calculator

A simple console-based calculator developed using C++.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus

## Concepts Used

- Variables
- User Input and Output
- Arithmetic Operators
- Switch Statements
- Conditional Logic

## How to Run

Compile and run `calculator.cpp` using a C++ compiler.

## Example

Enter first number: 10
Enter second number: 5
Enter symbol (+, -, *, /, %): +

Result = 15
